## 🚀 Como usar estes guias
1. Abra o arquivo `README.md` do Caso de Uso desejado.
2. Siga as instruções do tutorial **Passo a Passo** utilizando as imagens premium como referência visual.
3. Utilize os estereótipos e modificadores de acesso conforme especificado para garantir a conformidade técnica.
