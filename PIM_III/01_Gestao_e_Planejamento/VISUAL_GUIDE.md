# 🎨 Guia de Estilo Visual: Padrão Clean Contrast

Este guia define os padrões visuais utilizados na documentação UML do projeto Nex_TI. Após revisão, optou-se por um padrão de **Alto Contraste (Preto e Branco)** para garantir a melhor legibilidade possível.

## 🏁 Padrão de Modelagem (Astah)

Ao recriar os diagramas no Astah, siga estas diretrizes para manter a clareza:

| Elemento | Padrão Recomendado |
| :--- | :--- |
| **Fundo das Classes** | Branco ou Transparente |
| **Linhas e Bordas** | Preto (Solid Black) |
| **Fonte** | Arial ou Roboto (Tamanho 10 ou 12) |
| **Espaçamento** | Evite sobreposição de linhas de associação |

## 📐 Diretrizes Técnicas

### 1. Diagramas de Classe
- Utilize **Contorno Preto** e **Fundo Branco**.
- Mantenha os modificadores de acesso visíveis (`+` para Público, `-` para Privado).
- As setas de associação devem ser pretas e bem definidas.

### 2. Diagramas de Sequência
- As linhas de vida (`Lifelines`) devem ser brancas com contorno preto.
- Utilize barras de ativação (`Activation Bars`) para mostrar o processamento.
- Mantenha o texto das mensagens nítido sobre as setas.

*Este padrão prioriza a funcionalidade e a clareza técnica sobre a estética decorativa.*
